# episodes 目录说明

每期视频对应这里的一个子目录，命名为 `episode-NN`，  
NN 用两位数字编号，从 `01` 开始。

## 新建一期视频时

1. 新建 `episode-NN/` 子目录。
2. 从 `../templates/script.md` 复制一份到  
   `episode-NN/script.md`，按脚本格式填写。
3. 从 `../templates/metadata.md` 复制一份到  
   `episode-NN/metadata.md`，按发布信息填写。

`templates/` 下的文件本身不要直接编辑，  
它是每期都要复制一份的空白模板。
