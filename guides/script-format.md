# 视频脚本格式

## 结论

教程类视频脚本推荐使用要点式大纲（beat sheet），  
不建议用逐字稿。

逐字稿录出来容易念稿感很重，语速和画面节奏对不上；  
要点式大纲只列要讲什么，配音时用自己的话说，  
语流更自然，也更容易和画面拍子对齐。

## 组织方式

脚本按片段组织，和录制、剪辑用的文件编号一一对应，  
每个片段包含三块内容。

- **操作**：录片段时照着做的动作清单，  
  保证动作和顺序不漏、不忘。
- **要点**：配音时的提词依据，  
  只列关键词或短语，不写完整句子。
- **备注**：容易忘的细节和剪辑提示，  
  比如哪里可以跳过、哪里要停顿留给字幕。

## 示例

```text
## 片段 01 — 安装依赖

操作：
- 打开终端
- 执行 npm install
- 展示 package.json 的变化

要点：
- 为什么需要这一步
- 提醒容易踩的坑，比如网络超时

备注：
- 安装等待过程录屏时可以直接跳过不录
```

## 主要取舍

要点式大纲对临场表达要求更高，  
配音时需要能对着几个关键词说成一段流畅的话。  
如果还不习惯即兴讲解，可以先在要点下面加一行过渡句，  
熟练后再逐步只留关键词。

## 可复用模板

可复用的模板文件放在 `templates/` 下，  
每个模板旁边配一份同名的 `decision.md`，  
说明模板里每一部分为什么存在。
